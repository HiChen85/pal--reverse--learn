# 原创地图与剧情验收

地图和剧情保存在同一个内容包。地图事件通过稳定的剧情节点 ID 建立链接。打开 [《沿河寻名》](../examples/chapter-two.json) 可以试走原创渡口、触发剧情并使用已有的 Go 战斗和进度存取功能。

地图编辑支持 1–32 列、1–24 行，每个内容包最多 64 张地图，每张地图最多 128 个事件。`rows` 中的每行长度相同，只接受地面 `.` 与墙 `#`。`spawn` 和事件必须在地面上，每格最多一个事件。校验会从起点按上下左右搜索，报告找不到通路的事件。完全隔离且没有事件的地面可以保留。

下面是一个小地图。`river-arrival` 需要指向内容包中已经定义的节点。

```json
{
  "id": "landing",
  "name": "浅滩",
  "rows": ["####", "#..#", "####"],
  "spawn": {"x": 1, "y": 1},
  "events": [{"position": {"x": 2, "y": 1}, "node": "river-arrival"}]
}
```

用 `go run ./cmd/paltool validate examples/chapter-two.json` 可检查整个内容包。文件测试和编辑器应用使用同一套校验。合并时，扩展可以将地图事件链接到基础包的剧情节点。

「渡口浅滩」有两条验收路线。起点上方是墙，向上走应停在原地。向右走两格可调查渡口，从对白开始，问出三盏灯的意思后协助闻禾。打赢战斗后可以挂灯搭桥。也可以从起点向下两格再向右五格，直接调查缆索进入战斗。未打听灯语时，战斗后的选择只有送名单。

地图预览和剧情试玩分别记录状态。移动时不会更换正在试玩的剧情。点击「进入标记剧情」会从链接的节点开始一段新预览。剧情进度可以保存和恢复，地图试走坐标只用于当前预览。

执行两个地图试玩回归：

```sh
go test ./internal/studio -run '^TestMapPreview' -v
```

回归检查两条路线都从起点实际走到事件，每个战斗都经过 Go 回合，并核对结局节点及标记。另有内容包测试覆盖无效事件、错误尺寸、保存再加载及章节合并。原版资源格式的验证范围见 [输入数据记录](INPUT_DATA.md)。
