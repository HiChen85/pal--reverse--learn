# 原版逻辑会话保存

MyGo“原版数据”页的“保存会话 JSON”和“读取会话 JSON”用于继续已经提交的逻辑会话。先读取同一套本地游戏资源，再选择 JSON 路径并保存或读取。成功读取后刷新场景、待进入标记、库存、脚本入口和视口；读取失败保留当前会话。

此格式是 `pal-studio-session` version 1，不兼容原版 RPG 存档，也不证明检查点在原游戏中可达。“声明场景已进入”的诊断假设会随存档保留。正在执行的脚本和未结束战斗不支持保存。

存档保存完整世界、自动事件计时、脚本上下文、随机状态、执行预算和初始声明；绑定四张基础文件、DATA 运行表及所有已提供的 MGO/MAP/GOP/PAT/RNG/FBP 资源摘要。更换数据或省略原先绑定的资源会被拒绝。移动内容相同的资源目录不影响恢复。`fast_verify` 战斗策略也会保存和恢复，不能将其结果当作原数值战斗验收。

JSON 使用封闭字段集合、完整固定数组和载荷 SHA-256，拒绝重复字段、未知字段、非规范数字键、缺失字段和 null；最大 16 MiB。SHA-256 用于检查意外损坏，不是数字签名。文件替换采用同目录临时文件写入后重命名；导入资源、报告及其文件别名禁止作为存档输出。

回归比较连续执行与存取后执行的完整结果，覆盖移动、调查、菜单物品、随机战斗、已结束战斗摘要、待进入场景和预算错误。真实样本可选回归：

```sh
PAL_GAME_DATA_DIR="$PAL_DATA" go test ./internal/palgame -run TestLocalSaveResumeAfterOpening -v
```
