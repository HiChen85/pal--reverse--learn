## 已连续执行的客栈路线

`testdata/routes/sample-opening-wine-village.json` 固定七个文件摘要，仅包含数字ID、方向/菜单输入及消息断言，不包含台词、美术或地图数据。从新游戏开始，不设置 `AssumeSceneEntered`，不含显式 `trigger` 动作。

| 阶段 | 累计动作 | 实际结果 |
| --- | ---: | --- |
| 开场与卧室出口 | 14 | OnEnter完成，方向移动触碰卧室出口4，加载场景3 |
| 李大娘任务与厨房准备 | 170 | 两次触碰对话，自动行走使厨房李大娘出现 |
| 酒剑仙与厨房送菜条件 | 315 | 调查酒剑仙后回厨房对话，桌上事件入口改为可取酒菜 |
| 送酒菜 | 386 | 实际进入客房并触碰送菜事件16，获得物品272×1 |
| 使用桂花酒 | 441 | 菜单物品脚本与下一帧触碰完成交付，物品272归零，酒剑仙离场 |
| 买虾任务与出客栈 | 546 | 李大娘发放50，现金550，进入场景4 `(1248,896)` |
| 求药与出海 | 1084 | 大夫、小虎、李大娘与苗人对话，取得破天锤，登船骑乘航行，进入场景15 `(752,808)` |

运行：

```sh
go run ./cmd/palverify journey -data "$PAL_DATA" \
  -route testdata/routes/sample-opening-wine-village.json -out reports/opening-journey.json
PAL_GAME_DATA_DIR="$PAL_DATA" go test ./cmd/palverify -run TestLocalJourney -v
```

另有 `testdata/routes/sample-opening-island-landfall.json`：1084动作、372次消息引用，每动作均固定预期消息ID（包括空序列），终点保留破天锤279×1。使用 `-compact` 可生成约3MiB报告。新增 `sample-opening-six-statues.json`：1722动作、374消息引用，四场实际数值战斗后按真实路线使用破天锤完成六石像；事件238..243全0、263=1、279归零。原数值四战共16回合，显式 `fast_verify` 同路线共8回合，均保留脚本/奖励和断言。后续路线继续开发。

这是 Go 模型中的连续空间路线，不是原 APK 的完整实机对照。尚未完成的主线/支线继续开发；遇到阻塞记录实际 PC、opcode、输入与未提交原因，不能跳过后宣称通过。
