# Windows 98 柔情篇验证缺陷与后续队列

此清单区分已知能力缺口、外部阻塞与待目标数据证实的问题。它不是声称在原版实际运行中复现过下述所有故障。用户允许记录后续修复，不等于这些项目可被计为原版兼容通过。2026-11-05 阶段起点：目标游戏数据尚未提供，主支线原版实际回放未执行。

优先级：**P0** 阻止任何“原版主支线完整可运行”结论；**P1** 指定路径使用该功能时阻塞该路径；**P2** 可在明确降级的文字验证模式中延后，仍须公开记录。状态用 `blocked`（缺外部输入）、`open`（需实现/验证）、`pending-data`（尚不能定位原版实例）；只有附修复与复测证据才改为 `fixed/verified`。合成测试通过只注明 `synthetic-tested`。

## 修复与复审记录模板

每项修复追加：实际问题（不确定时注明）、最小输入/目标哈希、失败证据、负责 agent、修改位置、回归命令及输出、目标流程比较、主 agent 复审结论。不得以“代码已写”或“没有崩溃”直接关闭完整性问题。

## 当前允许延后的范围

在目标数据待提供时，可以继续交付源码证据、结构/引用静态审计、合成 VM 回归和原创扩展内容工作台。P0/P1 条目仍保留；完成这些工作并不表示原版主线或全部支线已可运行。P2 项可在明确说明的纯文字流程工具中延后；一旦用户验收目标涉及重绘后的完整游戏体验，需重新纳入验收。

## 本轮补齐记录（仍非原版流程验收）

- `internal/paldata`：有界 Windows 表读取、Big5/GBK、原始字节/控制串、文件 SHA-256、填充警告，已通过合成回归；主 agent 退回修正后支持末尾不完整词槽和未索引消息填充。
- `internal/palflow`：部分 trigger 控制流、明确随机/确认/外部战斗输入、返回入口、消息记录；未知 opcode/等待/预算不足均停止。未执行世界、自动脚本或真实战斗。
- `cmd/palverify`：摘要绑定路线、预期消息 ID 对照、默认不输出对白正文、失败轨迹保留、禁止用报告覆盖原版资源；相关 CLI 合成集成测试通过。
- D0–D4 原版目标数据验收仍未开始，WIN98-001/002 未关闭；真实支线数量仍未知。
