# 当前 PAL 数据样本

本次已取得可导入的 PAL 数据；它来自用户指定下载页所指向的 Android 包。**资源实际采用 DOS 风格布局及 YJ1 压缩，尚不能据“仙剑98柔情版”的名称认定为原 Windows 98 柔情篇发行数据。** 项目目标仍为用户指定的 PAL1 / Windows 98 柔情篇；当前样本按观测到的格式处理，后续再做发行版本对照。

## 来源与固定身份

来源页面：<https://m.downxia.com/downinfo/392031.html>。实际下载包 `pal98-v1.8.4.apk` 为 22,189,913 字节，SHA-256：

`5633d0a8c696345a705625f25db373b99c8c599a2450f787477ca2758c58363f`

Android 清单声明包名 `org.socool.pal`、版本 `1.8.4`；资源名称为“仙剑98柔情版（作弊菜单）”。这是 Android 包装版本和自称，不是原 PC 游戏发行版本的认证。包内含 SDL/PAL 原生库和 `assets/sdlpal/` 资源。本轮未安装或运行 APK，未对其联网；也没有运行实际 REA 引擎。

## 纯 Go YJ1 与 MGO 结果

`palcodec.DecodeYJ1` 已完成有界的树、位流、块长和反向引用解码；`palasset` 按需读取 MGO 并保存资源摘要、输出长度、帧数与帧目录异常。没有调用 APK 原生库，也未执行目标程序。

两片 MGO 本地还原为 1,577,442 字节，SHA-256 为 `a9f9fc0ceeccb354906a96eaf6003f9c7ece8db6789856144201d926f5ff76b1`。637 个块中 636 个非空精灵的 YJ1 流均完成解码，总输出 3,363,230 字节；按块顺序连接解码结果的 SHA-256 为 `1443697043cccb0ed0d3c70ce37daee88bd0f5ddf159a9b7f22f7798a11d0dfb`。这是解码输出一致性标识，不是图像视觉正确性或全部资源格式验收。

帧目录检查发现 **MGO #571 的 frame 0 结束偏移、frame 1 起始偏移越界**，两帧均被拒绝，不放宽边界。另有许多精灵的末帧终止 WORD 为零：仅在末帧完整有界 RLE 可解码且最多有一个填充字节时，允许以块末尾作为终点，并显式记录 `TerminalFallback`。实际 MAP #3 的169帧及 #12 的310帧均通过像素解码；MGO #571 仍保留异常。

当前已读取 MAP/GOP/MGO/PAT，加载场景、回填事件自动帧数并提供320×200静态地图视口及碰撞。图像预览没有淡入淡出、波纹、染色、RNG过场或音频播放；不能据静态画面推断完整表现兼容。

另外对 ABC #1、MGO #2/#21/#571，临时运行可信公开 SDLPAL 的独立 C 解压参考实现，与 Go 输出逐字节相同。只运行该公开源码解压器进行验证，未链接或加入项目，也未执行 APK 或其原生目标库。此比较确认这四个样本的解码输出，不证明所有资源的视觉或游戏行为一致。

## 初始入口与当前逻辑回放

静态数据中，场景 1 使用地图 12，进入入口 PC **7952**，传送入口 0，事件 ID 范围 **1–32**；场景 294 的终止索引为 5332。结合参考 SDLPAL 默认新游戏从场景 1 开始的规则，这是首段验证候选入口；包内存在 `0.rpg` 并不证明该 Android 客户端实际从这个存档启动。

入口 7952 至首个停止边界 8144 是可直接列出的指令段，包含音乐、位置、精灵、姿态、`0x0075` 编队、对话模式、等待、事件状态与移动；共有 67 条 `0xFFFF` 指令。8144 为 `0x0001`，按参考语义应将下次入口改为 8145，而 8145 为停止指令。这里的逐条清点是静态证据，不是原版流程回放。

场景 1 的活动触碰事件 1 入口为 4667：设置位置后，PC 4668 的 `0x0059` 请求转到场景 3。它提供后续验证“场景进入→事件触发→场景切换”的具体测试点；不应通过直接跳过移动、等待或未实现指令来宣称该流程完成。
